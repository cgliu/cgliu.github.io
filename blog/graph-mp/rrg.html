What is RRG method including Pros and Cons

RRG (Rapidly-exploring Random Graph) is a sampling-based motion planning algorithm introduced by Karaman & Frazzoli (IJRR 2011). Unlike RRT which builds a tree, RRG builds a graph by connecting each new sample to ALL nearby nodes within a computed radius, not just a single parent.

The key idea: when a new sample is added, connect it to every existing node within a ball of radius r(n) = γ · (log(n)/n)^(1/d), where n is the current number of nodes, d is the dimensionality, and γ is a tuning constant. This creates a richly connected graph that can be searched for optimal paths.

Pros

  • Asymptotically optimal: as the number of samples n → ∞, the cost of the best path in the graph converges to the true optimal path cost (almost surely). This is a property RRT does NOT have.
  • Rich connectivity: multiple edges per node means alternative routes are available; Dijkstra or A* can extract the shortest path post-construction.
  • Probabilistically complete: if a solution exists, RRG will find it given enough samples.
  • Simple to implement: the core loop is straightforward — sample, steer, connect to all near neighbors.

Cons

  • Higher memory usage: stores a full graph (many edges per node) vs. a tree (one parent per node). Edge count grows as O(n log n).
  • Slower per-iteration: must perform a radius-neighbor search and collision-check multiple edges at each step, compared to RRT's single parent connection.
  • Post-processing required: unlike RRT which gives an immediate start-to-goal tree path, RRG requires a graph search (Dijkstra) to extract the best path.
  • Parameter sensitivity: the γ constant must be tuned — too small leads to sparse connectivity, too large wastes computation on redundant edges.

How does it work

Algorithm Steps (per iteration)

  1. Sample: generate a random point x_rand uniformly in the configuration space.
  2. Find Nearest: locate the closest existing node x_nearest to x_rand.
  3. Steer: move from x_nearest toward x_rand by at most step_size to produce x_new.
  4. Collision Check: verify the segment from x_nearest to x_new is obstacle-free. If not, discard and repeat.
  5. Add Node: insert x_new into the graph.
  6. Compute Radius: calculate r(n) = γ · (log(n)/n)^(1/d).
  7. Connect to Neighbors: find ALL existing nodes within radius r(n) of x_new. For each, if the connecting segment is collision-free, add an undirected edge. This is the key step that differentiates RRG from RRT.
  8. Goal Check: if x_new is within goal_radius of the goal, stop building and run Dijkstra to find the shortest path.

Connection Radius Formula

r(n) = γ · (log(n) / n)^(1/d)
  • n = number of nodes currently in the graph
  • d = dimension of configuration space (2 for 2D planning)
  • γ = tuning constant (must exceed a theoretical threshold for optimality)

The radius shrinks as more nodes are added, so early iterations make long connections (ensuring connectivity) and later iterations make local ones (refining path quality).

Path Extraction

After the graph is built, Dijkstra's algorithm finds the shortest (least-cost) path from start to goal through the graph. The edge weights are Euclidean distances.

What is the connection with RRT, PRM methods

RRG sits between RRT and PRM, combining properties of both:

RRT (Rapidly-exploring Random Tree)

  • Builds a tree: each new node connects to exactly ONE parent (the nearest node or best-cost parent).
  • Explores space quickly by biasing growth toward unexplored regions.
  • NOT asymptotically optimal — the first feasible path found is typically suboptimal and cannot be improved since the tree structure is fixed.
  • RRT* improves on this by rewiring the tree, but still maintains tree structure.

PRM (Probabilistic Roadmap)

  • A multi-query method: first builds a graph (roadmap) by sampling many points and connecting neighbors, then answers multiple start/goal queries on the same graph.
  • Two-phase: construction phase (sample + connect) and query phase (graph search).
  • Asymptotically optimal but designed for static environments with repeated queries.

RRG's relationship to both

Property RRT RRG PRM
Structure Tree Graph Graph
Edges per node 1 (parent) Multiple Multiple
Asymptotically optimal No Yes Yes
Incremental Yes Yes No (batch)
Single-query Yes Yes No (multi)
Explores toward goal Yes Yes No (uniform)
  • RRG = RRT's incremental exploration + PRM's graph connectivity.
  • RRG keeps RRT's single-query, incremental sampling strategy (sample one point at a time, grow toward unexplored space), but adopts PRM's idea of connecting to multiple neighbors to form a graph.
  • RRT* is derived from RRG: it is RRG with the additional constraint that the graph must remain a tree (achieved by keeping only the best-cost parent edge and rewiring). RRT* ⊂ RRG in terms of edges retained.
  • The theoretical result (Karaman & Frazzoli 2011) proves that RRT is NOT asymptotically optimal, while RRG and RRT* both ARE, precisely because they connect to multiple neighbors within the shrinking radius r(n).

RRG under Partial Observability

Standard RRG assumes a fully known, static environment — the obstacle map is complete before planning begins. In practice, a robot has limited sensors (LiDAR, depth camera) with a finite field of view (FOV) and cannot see through walls. This section describes how to adapt RRG to partial observation.

The Core Problem

  • The robot only observes obstacles within its sensor cone/range.
  • Unobserved space is unknown — it might be free or occupied.
  • Edges in the graph that pass through unknown space cannot be validated.
  • The environment may also be dynamic (obstacles appear/disappear).

Approach: Interleave Planning and Execution (Receding-Horizon RRG)

The key idea is to run RRG incrementally as the robot moves, updating the graph with new sensor observations at each step:

1. Maintain Three-State Occupancy Map

Classify each region of space as one of:

  • Free: observed and confirmed empty.
  • Occupied: observed and confirmed obstacle.
  • Unknown: not yet observed (outside FOV or occluded).

This is typically stored as an occupancy grid or octree (e.g., OctoMap).

2. Optimistic vs. Pessimistic Edge Validation

Two strategies for treating unknown space during collision checking:

Strategy Unknown space treated as Effect
Optimistic Free Explores aggressively; may hit new
    obstacles and need to replan
Pessimistic Occupied Conservative; avoids unknowns but
    may get stuck in narrow corridors

A common middle ground: treat unknown as free for graph construction (sampling and connecting), but only commit to executing edges that pass through confirmed free space. This gives the planner a candidate path while keeping execution safe.

3. Incremental Graph Update Loop

while robot has not reached goal:
    1. Observe: update occupancy map from current sensor data
    2. Invalidate: remove/mark edges that now cross newly-discovered obstacles
    3. Grow: add new RRG samples in the newly-revealed free space
    4. Reconnect: attempt to reconnect orphaned subgraphs through new free space
    5. Replan: run Dijkstra on the updated graph for best current path
    6. Execute: follow the path for a short horizon (e.g., next few waypoints)
    7. Repeat from current position

4. Lazy Collision Checking

A practical optimization: don't collision-check every edge upfront. Instead:

  • Build the graph assuming all edges in unknown space are valid.
  • When Dijkstra returns a path, check only those edges for collisions against the current map.
  • If an edge is invalid, remove it, replan on the reduced graph.
  • This avoids wasting computation on edges the robot will never traverse.

This is the "Lazy" variant and applies well to RRG because of its dense connectivity — removing one invalid edge usually leaves alternative routes.

5. FOV-Aware Sampling Bias

Instead of sampling uniformly over the entire space, bias toward:

  • The frontier between known-free and unknown space (encourages exploration).
  • The region along the current best path (refines the route being followed).
  • The sensor FOV from the robot's current pose (samples here can be immediately validated).

6. Edge Confidence / Cost Augmentation

Assign higher traversal cost to edges passing through regions with fewer observations or high uncertainty. Dijkstra then naturally prefers well-observed routes: 

edge_cost(u, v) = euclidean(u, v) × (1 + α · uncertainty(u, v))

Where uncertainty(u, v) could be the fraction of the edge segment passing through unknown cells, and α is a risk-aversion parameter.

Key Advantages of RRG for Partial Observability

  • Redundant paths: the graph structure (vs. tree) means that when one edge is invalidated by a new obstacle, alternative routes likely exist without rebuilding from scratch.
  • Incremental growth: new samples integrate naturally as space is revealed.
  • Dijkstra re-query is cheap: after invalidating a few edges, re-running shortest-path on the existing graph is fast compared to rebuilding an entire plan. Specifically:
    • The graph (nodes + adjacency lists) already exists in memory — no sampling, steering, or collision-checking is needed to recreate it.
    • Dijkstra on a graph with n nodes and m edges runs in O((n + m) log n) with a binary heap. For a typical RRG with ~2000 nodes and ~10k edges, this is sub-millisecond on modern hardware.
    • Invalidating an edge is O(1) — just remove it from two adjacency lists. You don't recompute the entire graph topology.
    • Contrast with replanning from scratch: that requires re-sampling thousands of points, performing collision checks for each (expensive geometric queries), and rebuilding all connections. This is orders of magnitude slower than a graph search on an existing structure.
    • Further optimization: use D* Lite or LPA* instead of full Dijkstra. These algorithms propagate only the cost changes affected by the removed edges, making re-query even cheaper — often O(affected nodes) rather than O(entire graph).

Key Challenges

  • Graph maintenance cost: invalidating edges and checking consistency requires bookkeeping (adjacency updates, orphan detection).
  • Optimality loss: the graph was built under incomplete information, so the path is optimal w.r.t. current knowledge, not globally optimal.
  • Latency: sensor-to-replan loop must be fast enough for real-time execution — may need to limit graph size or use approximate NN search (kd-tree).

/**
 * Rapidly-Exploring Random Graph (RRG)
 *
 * RRG is a sampling-based motion planning algorithm that builds a graph
 * (not just a tree like RRT) by connecting new samples to ALL nearby nodes
 * within a ball of radius r(n) = gamma * (log(n)/n)^(1/d), where:
 *   - n = number of nodes in the graph
 *   - d = dimension of the configuration space
 *   - gamma = a tuning constant > threshold for asymptotic optimality
 *
 * Unlike RRT, RRG maintains multiple edges per node, forming a graph that
 * converges to optimal paths as the number of samples grows.
 *
 * Reference: Karaman & Frazzoli, "Sampling-based algorithms for optimal
 * motion planning", IJRR 2011.
 */

#include <algorithm>
#include <cmath>
#include <fstream>
#include <iostream>
#include <limits>
#include <random>
#include <sstream>
#include <vector>

// ---------- Configuration ----------

struct Point {
    double x;
    double y;

    double distanceTo(const Point& other) const {
        double dx = x - other.x;
        double dy = y - other.y;
        return std::sqrt(dx * dx + dy * dy);
    }
};

struct Obstacle {
    Point center;
    double radius;

    bool contains(const Point& p) const {
        return p.distanceTo(center) <= radius;
    }
};

struct Node {
    int id;
    Point position;
    std::vector<int> neighbors;  // adjacency list (graph edges)
};

// ---------- RRG Algorithm ----------

class RRG {
public:
    RRG(Point start, Point goal,
        double x_min, double x_max,
        double y_min, double y_max,
        double step_size,
        double goal_radius,
        int max_iterations,
        double gamma_rrg)
        : start_(start)
        , goal_(goal)
        , x_min_(x_min)
        , x_max_(x_max)
        , y_min_(y_min)
        , y_max_(y_max)
        , step_size_(step_size)
        , goal_radius_(goal_radius)
        , max_iterations_(max_iterations)
        , gamma_rrg_(gamma_rrg)
        , gen_(std::random_device{}())
        , dist_x_(x_min, x_max)
        , dist_y_(y_min, y_max)
    {
        // Add start node
        Node start_node;
        start_node.id = 0;
        start_node.position = start_;
        nodes_.push_back(start_node);
    }

    void addObstacle(const Obstacle& obs) {
        obstacles_.push_back(obs);
    }

    bool build() {
        for (int iter = 0; iter < max_iterations_; ++iter) {
            // 1. Sample a random point
            Point x_rand = sample();

            // 2. Find the nearest node
            int nearest_id = findNearest(x_rand);
            const Point& x_nearest = nodes_[nearest_id].position;

            // 3. Steer toward the random sample
            Point x_new = steer(x_nearest, x_rand);

            // 4. Check if the new point is collision-free
            if (!isCollisionFree(x_nearest, x_new)) {
                continue;
            }

            // 5. Add the new node
            int new_id = static_cast<int>(nodes_.size());
            Node new_node;
            new_node.id = new_id;
            new_node.position = x_new;
            nodes_.push_back(new_node);

            // 6. Find all nodes within the RRG radius
            double radius = computeRadius();
            std::vector<int> near_ids = findNear(x_new, radius);

            // 7. Connect to ALL collision-free neighbors within radius
            //    (This is the key difference from RRT: we form a GRAPH)
            for (int near_id : near_ids) {
                if (near_id == new_id) continue;
                if (isCollisionFree(nodes_[near_id].position, x_new)) {
                    addEdge(new_id, near_id);
                }
            }

            // Also ensure connection to nearest node if not already
            if (std::find(nodes_[new_id].neighbors.begin(),
                          nodes_[new_id].neighbors.end(),
                          nearest_id) == nodes_[new_id].neighbors.end()) {
                if (isCollisionFree(nodes_[nearest_id].position, x_new)) {
                    addEdge(new_id, nearest_id);
                }
            }

            // 8. Check if we reached the goal
            if (x_new.distanceTo(goal_) <= goal_radius_) {
                goal_node_id_ = new_id;
                std::cout << "Goal reached at iteration " << iter
                          << " with " << nodes_.size() << " nodes.\n";
                return true;
            }
        }

        std::cout << "Goal not reached after " << max_iterations_
                  << " iterations (" << nodes_.size() << " nodes).\n";
        return false;
    }

    // Find shortest path from start to goal using BFS/Dijkstra on the graph
    std::vector<Point> findShortestPath() const {
        if (goal_node_id_ < 0) return {};

        int n = static_cast<int>(nodes_.size());
        std::vector<double> dist(n, std::numeric_limits<double>::infinity());
        std::vector<int> prev(n, -1);
        std::vector<bool> visited(n, false);

        dist[0] = 0.0;

        // Simple Dijkstra
        for (int i = 0; i < n; ++i) {
            // Find unvisited node with minimum distance
            int u = -1;
            double min_dist = std::numeric_limits<double>::infinity();
            for (int j = 0; j < n; ++j) {
                if (!visited[j] && dist[j] < min_dist) {
                    min_dist = dist[j];
                    u = j;
                }
            }
            if (u == -1) break;
            visited[u] = true;

            // Relax neighbors
            for (int v : nodes_[u].neighbors) {
                double edge_cost = nodes_[u].position.distanceTo(nodes_[v].position);
                if (dist[u] + edge_cost < dist[v]) {
                    dist[v] = dist[u] + edge_cost;
                    prev[v] = u;
                }
            }
        }

        // Reconstruct path
        std::vector<Point> path;
        int current = goal_node_id_;
        while (current != -1) {
            path.push_back(nodes_[current].position);
            current = prev[current];
        }
        std::reverse(path.begin(), path.end());

        if (!path.empty() && path.front().distanceTo(start_) < 1e-9) {
            return path;
        }
        return {};  // No path found
    }

    // Statistics
    int getNodeCount() const { return static_cast<int>(nodes_.size()); }

    int getEdgeCount() const {
        int count = 0;
        for (const auto& node : nodes_) {
            count += static_cast<int>(node.neighbors.size());
        }
        return count / 2;  // each edge counted twice (undirected)
    }

    double getAverageDegree() const {
        if (nodes_.empty()) return 0.0;
        double total = 0.0;
        for (const auto& node : nodes_) {
            total += node.neighbors.size();
        }
        return total / nodes_.size();
    }

    const std::vector<Node>& getNodes() const { return nodes_; }
    const std::vector<Obstacle>& getObstacles() const { return obstacles_; }
    Point getStart() const { return start_; }
    Point getGoal() const { return goal_; }
    double getXMin() const { return x_min_; }
    double getXMax() const { return x_max_; }
    double getYMin() const { return y_min_; }
    double getYMax() const { return y_max_; }

    // Export the graph visualization as SVG
    void exportSVG(const std::string& filename,
                   const std::vector<Point>& path = {}) const {
        const int img_width = 800;
        const int img_height = 800;
        const int margin = 40;

        // Coordinate transform: world -> SVG pixels
        double sx = (img_width - 2.0 * margin) / (x_max_ - x_min_);
        double sy = (img_height - 2.0 * margin) / (y_max_ - y_min_);

        auto toSvgX = [&](double wx) {
            return margin + (wx - x_min_) * sx;
        };
        auto toSvgY = [&](double wy) {
            // Flip Y so that y increases upward
            return img_height - margin - (wy - y_min_) * sy;
        };

        std::ofstream out(filename);
        if (!out.is_open()) {
            std::cerr << "Error: could not open " << filename << " for writing.\n";
            return;
        }

        // SVG header
        out << "<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n";
        out << "<svg xmlns=\"http://www.w3.org/2000/svg\" "
            << "width=\"" << img_width << "\" height=\"" << img_height << "\" "
            << "viewBox=\"0 0 " << img_width << " " << img_height << "\">\n";

        // Background
        out << "  <rect width=\"" << img_width << "\" height=\"" << img_height
            << "\" fill=\"#f8f9fa\" stroke=\"#333\" stroke-width=\"2\"/>\n";

        // Title
        out << "  <text x=\"" << img_width / 2 << "\" y=\"25\" "
            << "text-anchor=\"middle\" font-family=\"sans-serif\" "
            << "font-size=\"16\" font-weight=\"bold\" fill=\"#333\">"
            << "Rapidly-Exploring Random Graph (RRG)</text>\n";

        // Draw obstacles
        for (const auto& obs : obstacles_) {
            double cx = toSvgX(obs.center.x);
            double cy = toSvgY(obs.center.y);
            double r = obs.radius * sx;  // scale radius
            out << "  <circle cx=\"" << cx << "\" cy=\"" << cy
                << "\" r=\"" << r << "\" fill=\"#e74c3c\" fill-opacity=\"0.6\" "
                << "stroke=\"#c0392b\" stroke-width=\"1.5\"/>\n";
        }

        // Draw graph edges (light gray, thin)
        out << "  <g stroke=\"#bdc3c7\" stroke-width=\"0.5\" stroke-opacity=\"0.6\">\n";
        for (const auto& node : nodes_) {
            for (int neighbor_id : node.neighbors) {
                // Only draw each edge once (when neighbor_id > node.id)
                if (neighbor_id > node.id) {
                    double x1 = toSvgX(node.position.x);
                    double y1 = toSvgY(node.position.y);
                    double x2 = toSvgX(nodes_[neighbor_id].position.x);
                    double y2 = toSvgY(nodes_[neighbor_id].position.y);
                    out << "    <line x1=\"" << x1 << "\" y1=\"" << y1
                        << "\" x2=\"" << x2 << "\" y2=\"" << y2 << "\"/>\n";
                }
            }
        }
        out << "  </g>\n";

        // Draw nodes (small blue dots)
        out << "  <g fill=\"#3498db\" fill-opacity=\"0.8\">\n";
        for (const auto& node : nodes_) {
            double cx = toSvgX(node.position.x);
            double cy = toSvgY(node.position.y);
            out << "    <circle cx=\"" << cx << "\" cy=\"" << cy
                << "\" r=\"2.5\"/>\n";
        }
        out << "  </g>\n";

        // Draw shortest path (thick green line)
        if (path.size() >= 2) {
            out << "  <polyline fill=\"none\" stroke=\"#27ae60\" "
                << "stroke-width=\"3\" stroke-linecap=\"round\" "
                << "stroke-linejoin=\"round\" points=\"";
            for (size_t i = 0; i < path.size(); ++i) {
                if (i > 0) out << " ";
                out << toSvgX(path[i].x) << "," << toSvgY(path[i].y);
            }
            out << "\"/>\n";

            // Draw path waypoints
            out << "  <g fill=\"#27ae60\">\n";
            for (size_t i = 1; i + 1 < path.size(); ++i) {
                double cx = toSvgX(path[i].x);
                double cy = toSvgY(path[i].y);
                out << "    <circle cx=\"" << cx << "\" cy=\"" << cy
                    << "\" r=\"4\"/>\n";
            }
            out << "  </g>\n";
        }

        // Draw start (green) and goal (red) markers
        double start_cx = toSvgX(start_.x);
        double start_cy = toSvgY(start_.y);
        out << "  <circle cx=\"" << start_cx << "\" cy=\"" << start_cy
            << "\" r=\"8\" fill=\"#2ecc71\" stroke=\"#1a9c4e\" stroke-width=\"2\"/>\n";
        out << "  <text x=\"" << start_cx << "\" y=\"" << start_cy + 20
            << "\" text-anchor=\"middle\" font-family=\"sans-serif\" "
            << "font-size=\"11\" fill=\"#1a9c4e\" font-weight=\"bold\">START</text>\n";

        double goal_cx = toSvgX(goal_.x);
        double goal_cy = toSvgY(goal_.y);
        out << "  <circle cx=\"" << goal_cx << "\" cy=\"" << goal_cy
            << "\" r=\"8\" fill=\"#e67e22\" stroke=\"#d35400\" stroke-width=\"2\"/>\n";
        out << "  <text x=\"" << goal_cx << "\" y=\"" << goal_cy + 20
            << "\" text-anchor=\"middle\" font-family=\"sans-serif\" "
            << "font-size=\"11\" fill=\"#d35400\" font-weight=\"bold\">GOAL</text>\n";

        // Legend
        int lx = img_width - 180;
        int ly = img_height - 120;
        out << "  <rect x=\"" << lx - 10 << "\" y=\"" << ly - 15
            << "\" width=\"170\" height=\"110\" fill=\"white\" "
            << "fill-opacity=\"0.9\" stroke=\"#ccc\" rx=\"5\"/>\n";
        out << "  <text x=\"" << lx << "\" y=\"" << ly
            << "\" font-family=\"sans-serif\" font-size=\"11\" fill=\"#333\">"
            << "<tspan font-weight=\"bold\">Legend</tspan></text>\n";
        // Edges
        out << "  <line x1=\"" << lx << "\" y1=\"" << ly + 15
            << "\" x2=\"" << lx + 20 << "\" y2=\"" << ly + 15
            << "\" stroke=\"#bdc3c7\" stroke-width=\"1.5\"/>\n";
        out << "  <text x=\"" << lx + 28 << "\" y=\"" << ly + 19
            << "\" font-family=\"sans-serif\" font-size=\"10\" fill=\"#555\">"
            << "Graph edges</text>\n";
        // Path
        out << "  <line x1=\"" << lx << "\" y1=\"" << ly + 33
            << "\" x2=\"" << lx + 20 << "\" y2=\"" << ly + 33
            << "\" stroke=\"#27ae60\" stroke-width=\"3\"/>\n";
        out << "  <text x=\"" << lx + 28 << "\" y=\"" << ly + 37
            << "\" font-family=\"sans-serif\" font-size=\"10\" fill=\"#555\">"
            << "Shortest path</text>\n";
        // Obstacle
        out << "  <circle cx=\"" << lx + 10 << "\" cy=\"" << ly + 51
            << "\" r=\"7\" fill=\"#e74c3c\" fill-opacity=\"0.6\"/>\n";
        out << "  <text x=\"" << lx + 28 << "\" y=\"" << ly + 55
            << "\" font-family=\"sans-serif\" font-size=\"10\" fill=\"#555\">"
            << "Obstacles</text>\n";
        // Start
        out << "  <circle cx=\"" << lx + 10 << "\" cy=\"" << ly + 69
            << "\" r=\"5\" fill=\"#2ecc71\"/>\n";
        out << "  <text x=\"" << lx + 28 << "\" y=\"" << ly + 73
            << "\" font-family=\"sans-serif\" font-size=\"10\" fill=\"#555\">"
            << "Start</text>\n";
        // Goal
        out << "  <circle cx=\"" << lx + 10 << "\" cy=\"" << ly + 87
            << "\" r=\"5\" fill=\"#e67e22\"/>\n";
        out << "  <text x=\"" << lx + 28 << "\" y=\"" << ly + 91
            << "\" font-family=\"sans-serif\" font-size=\"10\" fill=\"#555\">"
            << "Goal</text>\n";

        // Close SVG
        out << "</svg>\n";
        out.close();

        std::cout << "\nSVG visualization saved to: " << filename << "\n";
    }

private:
    Point sample() {
        return {dist_x_(gen_), dist_y_(gen_)};
    }

    int findNearest(const Point& p) const {
        int nearest = 0;
        double min_dist = std::numeric_limits<double>::infinity();
        for (int i = 0; i < static_cast<int>(nodes_.size()); ++i) {
            double d = p.distanceTo(nodes_[i].position);
            if (d < min_dist) {
                min_dist = d;
                nearest = i;
            }
        }
        return nearest;
    }

    std::vector<int> findNear(const Point& p, double radius) const {
        std::vector<int> near;
        for (int i = 0; i < static_cast<int>(nodes_.size()); ++i) {
            if (p.distanceTo(nodes_[i].position) <= radius) {
                near.push_back(i);
            }
        }
        return near;
    }

    Point steer(const Point& from, const Point& to) const {
        double d = from.distanceTo(to);
        if (d <= step_size_) {
            return to;
        }
        double ratio = step_size_ / d;
        return {
            from.x + ratio * (to.x - from.x),
            from.y + ratio * (to.y - from.y)
        };
    }

    // Collision check: verify the segment from 'a' to 'b' doesn't hit obstacles
    bool isCollisionFree(const Point& a, const Point& b) const {
        // Check if endpoints are in free space
        for (const auto& obs : obstacles_) {
            if (obs.contains(a) || obs.contains(b)) {
                return false;
            }
        }

        // Check along the segment at discrete intervals
        double d = a.distanceTo(b);
        int steps = std::max(2, static_cast<int>(d / 0.1));
        for (int i = 1; i < steps; ++i) {
            double t = static_cast<double>(i) / steps;
            Point p = {a.x + t * (b.x - a.x), a.y + t * (b.y - a.y)};
            for (const auto& obs : obstacles_) {
                if (obs.contains(p)) {
                    return false;
                }
            }
        }
        return true;
    }

    // RRG connection radius: r(n) = gamma * (log(n)/n)^(1/d)
    double computeRadius() const {
        int n = static_cast<int>(nodes_.size());
        if (n <= 1) return step_size_ * 2.0;

        constexpr int d = 2;  // 2D space
        double r = gamma_rrg_ * std::pow(std::log(static_cast<double>(n)) / n, 1.0 / d);
        // Clamp to step_size to avoid disconnected components early on
        return std::max(r, step_size_);
    }

    void addEdge(int u, int v) {
        // Undirected graph: add both directions
        nodes_[u].neighbors.push_back(v);
        nodes_[v].neighbors.push_back(u);
    }

    // Configuration
    Point start_, goal_;
    double x_min_, x_max_, y_min_, y_max_;
    double step_size_;
    double goal_radius_;
    int max_iterations_;
    double gamma_rrg_;

    // State
    std::vector<Node> nodes_;
    std::vector<Obstacle> obstacles_;
    int goal_node_id_ = -1;

    // Random number generation
    std::mt19937 gen_;
    std::uniform_real_distribution<double> dist_x_;
    std::uniform_real_distribution<double> dist_y_;
};

// ---------- Main ----------

int main() {
    // Define the planning problem
    Point start = {1.0, 1.0};
    Point goal  = {9.0, 9.0};

    // Parameters
    double x_min = 0.0, x_max = 10.0;
    double y_min = 0.0, y_max = 10.0;
    double step_size = 0.5;
    double goal_radius = 0.5;
    int max_iterations = 5000;
    double gamma_rrg = 10.0;  // Tuning constant for connection radius

    RRG rrg(start, goal, x_min, x_max, y_min, y_max,
            step_size, goal_radius, max_iterations, gamma_rrg);

    // Add some circular obstacles
    rrg.addObstacle({{3.0, 3.0}, 1.0});
    rrg.addObstacle({{5.0, 5.0}, 1.5});
    rrg.addObstacle({{7.0, 3.0}, 1.0});
    rrg.addObstacle({{3.0, 7.0}, 1.0});
    rrg.addObstacle({{7.0, 7.0}, 0.8});

    std::cout << "=== Rapidly-Exploring Random Graph (RRG) ===\n";
    std::cout << "Start: (" << start.x << ", " << start.y << ")\n";
    std::cout << "Goal:  (" << goal.x << ", " << goal.y << ")\n";
    std::cout << "Space: [" << x_min << "," << x_max << "] x ["
              << y_min << "," << y_max << "]\n";
    std::cout << "Step size: " << step_size << "\n";
    std::cout << "Gamma (connection radius): " << gamma_rrg << "\n\n";

    // Build the graph
    bool found = rrg.build();

    // Print statistics
    std::cout << "\n--- Graph Statistics ---\n";
    std::cout << "Nodes: " << rrg.getNodeCount() << "\n";
    std::cout << "Edges: " << rrg.getEdgeCount() << "\n";
    std::cout << "Average degree: " << rrg.getAverageDegree() << "\n";

    // Find and print shortest path
    if (found) {
        auto path = rrg.findShortestPath();
        if (!path.empty()) {
            std::cout << "\n--- Shortest Path (Dijkstra) ---\n";
            std::cout << "Path length: " << path.size() << " waypoints\n";
            double total_cost = 0.0;
            for (size_t i = 1; i < path.size(); ++i) {
                total_cost += path[i - 1].distanceTo(path[i]);
            }
            std::cout << "Path cost: " << total_cost << "\n";
            std::cout << "Waypoints:\n";
            for (size_t i = 0; i < path.size(); ++i) {
                std::cout << "  [" << i << "] (" << path[i].x << ", "
                          << path[i].y << ")\n";
            }

            // Export SVG with path highlighted
            rrg.exportSVG("rrg_output.svg", path);
        } else {
            std::cout << "\nNo path found in graph (disconnected).\n";
            rrg.exportSVG("rrg_output.svg");
        }
    } else {
        // Export SVG even if goal not reached (shows exploration)
        rrg.exportSVG("rrg_output.svg");
    }

    return 0;
}
